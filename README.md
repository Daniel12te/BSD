## 📖 Descripción del Proyecto
Bavaria Smart Dispatch es un módulo web integral diseñado para la gestión inteligente, 
optimización de rutas y control de despachos logísticos. Este proyecto Full Stack busca digitalizar y agilizar 
el proceso operativo mediante una interfaz de usuario dinámica y un backend robusto que garantiza 
la seguridad y persistencia de los datos.

## 🛠️ Stack Tecnológico

**Frontend:**
* React.js (Inicializado con Vite)
* JavaScript / JSX
* HTML5 & CSS3

**Backend & Infraestructura:**
* Java 21
* Spring Boot
* Spring Security (Gestión de accesos y CORS)
* Spring Data JPA
* Base de Datos: Oracle Database
* Infraestructura: Máquina Virtual con Ubuntu Server

## ✨ Características Principales
* **Arquitectura RESTful:** Comunicación fluida entre el cliente y el servidor mediante peticiones HTTP.
* **Seguridad Configurada:** Implementación de CORS y filtros de seguridad para protección de endpoints.
* **Gestión de Datos:** Persistencia estructurada mediante entidades JPA y repositorios.
* **Interfaz Reactiva:** Frontend modular construido con componentes de React para una experiencia ágil.
